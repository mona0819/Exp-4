# AIM:

To design and develop various UML diagrams for the Hospital Management System, including Use Case Diagram, Class Diagram, Sequence Diagram, Communication Diagram, Activity Diagram, and Package Diagram to represent the system's structure, behavior, and interactions.

# SRS (Procedure):

1. Identify the requirements and objectives of the Hospital Management System.
2. Identify the actors involved in the system, such as Admin, Doctor, Patient, and Receptionist.
3. Draw the Use Case Diagram to represent the interactions between actors and the system.
4. Draw the Class Diagram to represent classes, attributes, methods, and relationships.
5. Draw the Sequence Diagram to represent the sequence of interactions between objects.
6. Draw the Communication Diagram to represent communication between objects.
7. Draw the Activity Diagram to represent the workflow of hospital activities.
8. Draw the Package Diagram to organize the system into different modules.
9. Verify all diagrams to ensure that they represent the system requirements correctly.
